# 华为 3.98″ 四色墨水屏 · A0/A1 中间杠解决方案

> 本文是整个仓库的核心。面向:买了华为 3.98 寸 768×552 四色柔性墨水屏(配 ESP32-C3),
> 刷了网上常见固件后,屏幕**中间出现一道竖缝 / 白条、下半屏左右镜像**的人。
> 结论来自真机反复实验,不是理论推测。

---

## 一、先认清问题:这不是物理损坏

**现象**:屏幕买来时中间是完整画面;刷了通用固件后,出现一条贯穿的竖缝,
下半屏内容左右颠倒。很多人第一反应是"屏幕排线坏了 / 物理中缝"。

**真相**:这批屏有两种硬件批次 —— **A0** 与 **A1**,可见区都是 768×552,
外观完全一样,但**栅极寻址方式不同**。网上绝大多数固件只按 A0 写。
把 A0 的帧几何套到 A1 屏上,就是"下半屏镜像 + 中间割裂"的根因。

> 认知坑:曾一度误判为物理中缝,还拿"三条黑带缺口落在同一位置"当证据。
> 真机决定性反证:按顺序栅极写 0..599 得到**连续无割裂**的画面(仅右下被可见区裁掉)。
> 契约 + 真机才是最终裁判,不是一张照片。

---

## 二、根因:A0 与 A1 的栅极映射差异

| 项 | A0 | A1(本案例) |
|---|---|---|
| 可见区 | 768×552 | 768×552 |
| 栅极寻址 | Y 隔行映射到两个半屏:`j<H/2 ? 2j : 2(H-j)-1` | **顺序寻址 0..551** |
| 行内变换 | — | 固定整行镜像 |
| 帧打包 | — | 180° 预旋转 + 顺序栅极 + 整行镜像 |
| 用错后果 | — | 下半屏镜像、中间竖缝 |

把 A0 的隔行映射打到 A1 屏 → 本该连续的栅极被打散到两个半屏 →
中间出现分界缝,下半屏左右颠倒。**这就是"中间一条杠"的全部秘密。**

---

## 三、A1 唯一正解(契约)

来自 MoInk R1.4.0 `docs/CONTRACT.md` §4,2026-09-23 真机定案 FB-013:

| 项 | A1 正解 |
|---|---|
| 帧几何 | **768×552**(唯一档;800×600 只是诊断档,已下线) |
| TRES / 刷新窗 | 768×600,写入窗 `(0..767, 0..551)` |
| 行 → 栅极 | 顺序 `y = i`,1:1 落在 552 条可见栅极 |
| 行内变换 | **固定整行镜像**(缓冲按 180° 契约打包) |
| 初始化 | JD79665 式(0xAA 解锁 + 0x65/0x84 级联),BUSY 窗口 180s |

帧打包的关键实现(见 `scripts/mfink_http_pattern.py` 的 `pack_2bpp`):

```python
for r in range(h):
    ro = (h - 1 - r) * w          # 行序反转 → 180° 预旋转的一半
    for xb in range(rb):
        xa = w - 4 - (xb << 2)    # 行内字节倒序 → 整行镜像
        out[r, xb] = ((idx[ro+xa+3] << 6) | (idx[ro+xa+2] << 4) |
                      (idx[ro+xa+1] << 2) | idx[ro+xa])
```

## 六、两条独立故障线(最容易混的地方)

这是本案例最大的教训:**"中间杠"和"刷不上屏"是两个完全不同的问题**,
不要因为都表现为"屏幕不对"就混为一谈。

### 故障线 A:映射问题(固件可解)
A0/A1 栅极映射错 → 中间竖缝、下半屏镜像。**刷对固件 + 设 A1 即解**,
证据见第四、五节。

### 故障线 B:EPD 卡图 / 刷屏失败(硬件层)
表现:网页报"刷屏失败:多半是屏幕没插好或排线松了",或返回 OK 但
`/api/info` 持续 `last=-1`、屏幕停在旧图(残影)。

**这条线换固件解决不了**,按概率排查:
1. **USB 供电**:四色全刷瞬间电流大,线细/接触差会掉压 → 换根粗的、短的、能传数据的 USB 线,插主机后面的口。
2. **FPC 排线接触**:断电拔下,橡皮轻擦金手指,重插到底压紧卡扣;万用表测"通"不等于"接触电阻够小"。
3. **BUSY 信号线**(ESP32-C3 接 GPIO10):接触不良会让固件读不到忙/闲状态,**误报刷屏失败**——屏幕可能其实刷上了。
4. 都不行 → 换排线,再不行 → 屏本身。

> 判据:网页红字"**与设备失去连接 / 上传超时**"= 真网络层;
> "**刷屏失败:请检查屏幕连接**" = 图已送达、EPD 没刷成 = 硬件层。别修错方向。

## 七、边界与未决

- 本方案针对 **768×552 华为四色柔性屏 + ESP32-C3**;其他尺寸 / 主控不保证适用。
- 映射正解在真机上为 `局部实测`(四角方位图正确);完整长期可靠性未做量产级验证。
- 故障线 B(卡图 / 刷屏失败)在本次实物上**未彻底解决**,倾向排线 / 供电 / 屏硬件,
  属独立问题,不在本固件的解决范围。
- RST 接线因批次而异:有板子需要 RST 接 GPIO3(MoInk 默认),有的按 GPIO2;
  接线与固件预设不匹配会直接"不刷新",排查时先核对这一项。
